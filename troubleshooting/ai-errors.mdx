## Error reference

| Symptom / message | Likely cause | What to do |
| --- | --- | --- |
| Complete AI setup first | No default model selected, or Key is empty | [Model configuration](/modules/models) |
| Invalid API Key | Wrong or expired Key | Update the Key |
| Request timed out | Slow network or slow model response | Lower [concurrency / chunking](/models/runtime-config) |
| Too many requests (429) | Rate limit hit | Lower concurrency and retry later |
| JSON parse failed | Model did not follow the output format | Check [prompts](/models/prompts) |
| Structure mismatch | Returned keys do not match the input | Retry or switch models |
| Insufficient tokens | Platform quota exhausted | [Quotas](/account/quotas) or switch to a custom model |

## Custom models

- **Endpoint unreachable** — Check the URL, VPN, and firewall
- **Ollama CORS** — Ensure Ollama allows the browser origin
- **Mixed Content** — HTTPS pages blocking requests to an HTTP local API

## Network

Confirm you can reach the API endpoint; for corporate proxies, configure the system proxy or switch to a reachable relay Endpoint.
