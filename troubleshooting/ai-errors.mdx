## 错误对照

| 现象 / 提示 | 可能原因 | 处理 |
| --- | --- | --- |
| 请先完成 AI 配置 | 未选默认模型或 Key 为空 | [模型配置](/models/overview) |
| API Key 无效 | Key 错误或过期 | 更新 Key |
| 请求超时 | 网络慢或模型响应慢 | 降低 [并发/分片](/models/runtime-config) |
| 请求过于频繁 (429) | 触发速率限制 | 降低并发，稍后重试 |
| JSON 解析失败 | 模型未按格式输出 | 检查 [提示词](/models/prompts) |
| 结构不匹配 | 返回 key 与输入不一致 | 重试或换模型 |
| Token 不足 | 平台额度用尽 | [配额](/account/quotas) 或换自定义模型 |

## 自定义模型专项

- **Endpoint 不可达** — 检查 URL、VPN、防火墙
- **Ollama CORS** — 确保 Ollama 允许浏览器来源
- **Mixed Content** — HTTPS 页面请求 HTTP 本地 API 会被拦截

## 网络

确认可访问 API 端点；企业代理需配置系统代理或改用可访问的中转 Endpoint。
