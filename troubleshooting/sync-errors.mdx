## Layer cloud sync

| Symptom | What to do |
| --- | --- |
| Pro membership required | [Upgrade your plan](/account/plans) |
| Not signed in | [Sign in](/journey/login) |
| Sync conflict / incorrect data | First [export a local backup](/sync/local-import-export), then pull or push in one direction |
| Request failed | Check the network and API service status |

## Local import

| Symptom | What to do |
| --- | --- |
| No importable data detected | Confirm the JSON format is compatible with the export version |
| Site missing after import | Check the `translationGroups` field in the JSON |

## Google Drive

| Symptom | What to do |
| --- | --- |
| Authorization failed | Re-authorize the Google account |
| Sync failed | Review the error details; confirm Drive API quota |
| Backup list is empty | Complete one successful sync first |

## Auto sync

If the auto-sync interval is too short, it may conflict with other operations. Increase the interval in minutes as needed.
