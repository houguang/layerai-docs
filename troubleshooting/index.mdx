This page collects common LayerAI issues and investigation tips, ordered from basic checks to more specific cases.

## Investigation order

<Steps>
  <Step title="Confirm the extension is enabled">
    On the browser extensions page, confirm LayerAI is turned on and that the target site has been granted access.
  </Step>
  <Step title="Check auto-replace">
    Confirm **Auto-replace** is enabled in the popup, and that the relevant entries are not disabled.
  </Step>
  <Step title="Browse by category">
    AI issues → [AI errors](/troubleshooting/ai-errors); sync → [Sync errors](/troubleshooting/sync-errors).
  </Step>
</Steps>

## Common issues

<AccordionGroup>
  <Accordion title="Extension icon is gray / popup will not open">
    Reload the extension; check whether it is disabled by browser policy.
  </Accordion>
  <Accordion title="No manual collect button on the page">
    Confirm the current URL is not a browser internal page (chrome://, edge://, and similar); refresh the page.
  </Accordion>
  <Accordion title="Cannot collect text">
    The page may render with Shadow DOM or Canvas; try [Manual collection](/collection/manual).
  </Accordion>
  <Accordion title="Replacement is incomplete">
    Check [Replacement modes](/replace/modes); dynamically loaded content may need to be collected again.
  </Accordion>
  <Accordion title="Sign-in failed">
    Clear the site cookies and try again; check the network and system time.
  </Accordion>
</AccordionGroup>

## Still unresolved

Contact support through the feedback channel on the basic settings page, and include: browser version, problem URL, repro steps, and console logs.
