LayerAI is a browser extension for **foreign-language sites whose page content is relatively stable**. It collects page text, saves confirmed translations, and **auto-replaces** them on return visits—so you do not re-translate the same page every time.

## Who it is for

| Fit | Examples |
| --- | --- |
| **Good fit** | Docs, product pages, help centers, admin / SaaS UIs—copy changes infrequently |
| **Poor fit** | News feeds, social media, live rankings—source text changes often; use an instant translator instead |

## How it works

1. **Collect** — Extract text from the current page or site
2. **Translate & save** — AI batch or manual review, then persist entries locally
3. **Reuse** — On return visits, saved translations apply automatically (no re-translation)

<AccordionGroup>
  <Accordion title="Compared with instant translation">
    Instant translators re-translate on every page load—best for one-off reading. LayerAI persists reviewed translations so wording stays stable and reusable.

    | Capability | LayerAI | Instant translation |
    | --- | --- | --- |
    | Apply saved translations on return visits | ✓ | — |
    | Save and manually refine translations | ✓ | — |
    | Glossary-constrained terms | ✓ | Partial |
    | Whole-site batch collection / queue | ✓ | — |
    | Read immediately with zero setup | Needs prior save | ✓ |
    | Frequently updating pages | Re-collect when source changes | ✓ |
  </Accordion>

  <Accordion title="Privacy and data">
    Translation data is stored in the browser locally by default. Core features do not require an account. The extension does not use the pages you visit for model training.

    After sign-in you can opt into cloud sync and shared translations. Site permissions are requested only when needed for collection and replace; you can revoke them in browser extension settings. Backups: [local import/export](/sync/local-import-export) or [Google Drive](/sync/google-drive).
  </Accordion>
