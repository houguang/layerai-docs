## Supported platforms

| Platform | Description |
| --- | --- |
| **OpenAI-compatible** | OpenAI, Azure, and various relay APIs |
| **Anthropic** | Claude family |
| **Gemini** | Google Gemini API |
| **Ollama** | Open-source models running locally |

## Setup steps

<Steps>
  <Step title="Add a custom model">
    Model configuration → Add model → enter name, platform, and model ID
  </Step>
  <Step title="Enter credentials">
    API key and endpoint (for Ollama, use a local address such as `http://127.0.0.1:11434`)
  </Step>
  <Step title="Set as default">
    Select the model in the default model dropdown
  </Step>
  <Step title="Test translation">
    Run a small AI translation on any page to verify
  </Step>
</Steps>

<Warning>
  API keys are stored locally in the browser. Do not configure production keys on shared devices.
</Warning>

## Local Ollama deployment

Make sure the Ollama service is running and reachable from the browser on the configured port. For CORS or Mixed Content issues, see [Troubleshooting](/troubleshooting/ai-errors).
