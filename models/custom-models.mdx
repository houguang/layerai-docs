## 支持的平台

| 平台 | 说明 |
| --- | --- |
| **OpenAI 兼容** | OpenAI、Azure、各类中转 API |
| **Anthropic** | Claude 系列 |
| **Gemini** | Google Gemini API |
| **Ollama** | 本地运行的开源模型 |

## 配置步骤

<Steps>
  <Step title="添加自定义模型">
    模型配置 → 添加模型 → 填写名称、平台、模型 ID
  </Step>
  <Step title="填写凭据">
    API Key、Endpoint（Ollama 填本地地址如 `http://127.0.0.1:11434`）
  </Step>
  <Step title="设为默认">
    在默认模型下拉框中选择该模型
  </Step>
  <Step title="测试翻译">
    在任意页面发起小规模 AI 翻译验证
  </Step>
</Steps>

<Warning>
  API Key 保存在浏览器本地，请勿在公共设备上配置生产密钥。
</Warning>

## Ollama 本地部署

确保 Ollama 服务已启动且浏览器可访问对应端口。CORS 或 Mixed Content 问题参见 [故障排查](/troubleshooting/ai-errors)。
