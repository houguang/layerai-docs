Model configuration → **Prompts**.

## Structure

- **System Prompt** — Defines the translation engine role and output format (JSON)
- **User Prompt** — User-side instructions, typically including a target-language placeholder

## Default behavior

Built-in prompts instruct the model to:

- Output JSON only, with keys matching the input one-to-one
- Preserve the `{{@identifier#index|source}}` placeholder structure
- Leave identifying content such as addresses, IDs, and brand names unchanged

## Customization tips

- Add tone guidance for your domain (formal / conversational)
- Add constraints such as “must use glossary terms” (with [Glossary](/modules/glossary))
- Avoid breaking the JSON output format, or parsing will fail

## Manual translation

The [manual translation](/translation/manual-translation) workflow copies the current prompts and batched JSON.
