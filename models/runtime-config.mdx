Model configuration → **Runtime parameters** (or related advanced translation settings).

## Parameters

| Parameter | Purpose | Guidance |
| --- | --- | --- |
| **Batch size (batchSize)** | Number of items per API request | Too large may exceed token limits; too small increases request count |
| **Concurrency** | Number of concurrent requests | Adjust based on API rate limits |
| **Retry count (retryCount)** | Retries after a batch fails | Increase moderately on unstable networks |

## Relationship to the queue

These parameters apply to batch jobs in the [translation queue](/modules/queue). They do not affect single-item manual edits.

## Troubleshooting

Frequent timeouts or HTTP 429 rate limits → lower concurrency or batch size. See [AI error troubleshooting](/troubleshooting/ai-errors).
