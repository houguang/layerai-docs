模型配置 → **运行时参数**（或翻译相关高级设置）。

## 参数说明

| 参数 | 作用 | 建议 |
| --- | --- | --- |
| **分片大小（batchSize）** | 单次 API 请求包含的条数 | 过大易超 token 上限；过小请求次数多 |
| **并发（concurrency）** | 同时进行的请求数 | 按 API 速率限制调整 |
| **重试次数（retryCount）** | 单分片失败后的重试 | 网络不稳时可适当提高 |

## 与队列的关系

这些参数作用于 [翻译队列](/queue/overview) 中的批量任务，不影响单条手动编辑。

## 排错

频繁超时或 429 限流 → 降低并发或分片大小，参见 [AI 错误排查](/troubleshooting/ai-errors)。
