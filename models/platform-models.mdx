## 使用条件

- [登录 Layer 账号](/journey/login)
- 账户 Token 额度未用尽

## 选择模型

模型配置页 → **默认模型** → 选择带 Platform 标识的模型。

## 额度查看

基础配置 → **账号** 区域查看：

- Free 模型 Token
- Pro 模型 Token
- Max 模型 Token

额度按套餐与周期重置，详见 [配额说明](/account/quotas)。

## 故障

额度不足或模型不可用时，AI 翻译会失败。可改用 [自定义模型](/models/custom-models) 或升级套餐。
