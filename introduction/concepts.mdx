This page covers LayerAI’s design model and key terms. For a hands-on walkthrough, see [Your first translation](/journey/first-translation).

## Persistent translations

LayerAI collects source text and saves confirmed translations. When **page content has not changed**:

- Already translated content does not need re-translation
- Return visits auto-apply saved translations (with auto-replace on)
- Data is stored locally by default; back up via [export JSON](/sync/local-import-export)

After signing in, Pro / Max users can also use [cloud sync](/sync/layer-cloud) and [shared translations](/modules/shared).

## Translate once, reuse while unchanged

LayerAI splits foreign-language reading into two stages:

1. **Translate** — Collect, translate, review, and save on the page
2. **Reuse** — On later visits, apply saved translations automatically—unlike instant translation, which re-translates every load

When source text changes, re-collect or fill gaps. Day-to-day reading should feel like a native-language page.

## Data model

### Site (Translation Group)

Entries are aggregated by **domain**. For example, all entries under `docs.layerai.yun` belong to the same site.

### Entry (Translation Item)

| Field | Description |
| --- | --- |
| **Source** | Text collected from the page |
| **Target** | Stored per language, e.g. `{ "zh-CN": "Queue" }` |
| **Locator** | DOM location (such as XPath) for exact replace |
| **Enabled** | Disable an individual translation without deleting it |

### Glossary

Term categories and entries that constrain AI output. See [Glossary](/modules/glossary).

## Replace modes

<AccordionGroup>
  <Accordion title="Exact replace (exact)">

  </Accordion>
  <Accordion title="Content-match replace (content_match)">
    Finds and replaces by source text. Useful for reuse across pages or manually maintained general entries.
  </Accordion>
</AccordionGroup>
