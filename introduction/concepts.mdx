## 本地优先

LayerAI 的翻译数据默认保存在浏览器本地。这意味着：

- 已翻译内容**无需重复调用 AI**，节省 Token 与等待时间
- 再次访问同一页面时，扩展自动应用已保存的译文
- 你可以随时 [导出 JSON](/sync/local-import-export) 备份或在其他设备恢复

登录 Layer 账号后，Pro / Max 用户还可使用 [云同步](/sync/layer-cloud) 与 [共享翻译](/shared/overview)。

## 一次翻译，永久生效

典型工作流：

```
访问网页 → 采集文本 → AI/手动翻译 → 保存 → 页面自动替换
                ↑                                    │
                └──────── 再次访问时自动应用 ─────────┘
```

## 三层界面

| 界面 | 入口 | 用途 |
| --- | --- | --- |
| **浏览器弹窗** | 点击扩展图标 | 快速采集、开关自动替换、下载共享翻译 |
| **选项页** | 弹窗内「管理」或右键扩展 → 选项 | 翻译管理、队列、词库、模型、同步 |
| **网页浮层** | 页面右侧按钮 / 翻译列表 | 在当前页查看、编辑、保存词条 |

详见 [界面导览](/introduction/ui-tour)。

## 数据模型

### 站点（Translation Group）

按**域名**聚合，例如 `docs.example.com` 下的所有词条属于同一站点配置。

### 词条（Translation Item）

每条词条包含：

- **原文（source）** — 页面上采集到的文本
- **译文（target）** — 按目标语言存储，如 `{ "zh-CN": "队列" }`
- **定位（locator）** — XPath 等 DOM 定位信息，用于精确替换
- **启用状态** — 可单独禁用某条译文

### 词库（Glossary）

术语分类与条目，在 AI 翻译时约束品牌名、产品名等译法。详见 [词库概述](/glossary/overview)。

## 替换模式

<AccordionGroup>
  <Accordion title="精确替换（exact）">
    根据采集时的 DOM 定位替换文本，适合大多数网页场景。手动添加的词条在精确模式下不可用。
  </Accordion>
  <Accordion title="内容匹配替换（content_match）">
    按原文内容在页面中查找并替换，适合跨页面复用相同译文，或手动维护的通用词条。
  </Accordion>
</AccordionGroup>

详见 [替换模式](/replace/modes)。
