## 浏览器弹窗

点击工具栏中的 LayerAI 图标打开弹窗，常用操作：

| 区域 | 功能 |
| --- | --- |
| 账号区 | 登录状态、套餐标识（Free / Pro / Max） |
| 采集功能 | 手动采集、一键采集当前页 / 当前网站 |
| 自动替换 | 开关页面译文替换 |
| 替换模式 | 精确替换 / 内容匹配替换 |
| 共享翻译 | 发现可下载的社区翻译包时快捷下载 |

## 选项页（管理后台）

通过弹窗「管理」或浏览器扩展菜单 → **选项** 进入，侧边栏模块：

| 模块 | 说明 |
| --- | --- |
| 翻译管理 | 按站点浏览、编辑词条，发起 AI 翻译 |
| 翻译队列 | 查看批量翻译任务进度 |
| 词库管理 | 维护本地与平台术语 |
| 共享翻译 | 浏览、下载、提交共享包 |
| 模型配置 | 默认模型、提示词、运行时参数 |
| 导入/导出 | 本地 JSON、云同步、Google Drive |
| 基础配置 | 语言、主题、账号、共享发现策略 |
| 开发者配置 | 调试日志、受保护标签、敏感词脱敏 |

## 网页内浮层

访问已启用扩展的页面时：

- **手动采集按钮** — 页面边缘悬浮，点击进入框选采集模式
- **翻译列表弹窗** — 展示当前页已采集词条，支持编辑、AI 翻译、保存
- **共享翻译提示** — 发现匹配共享包时，按设置弹窗或图标提醒

<Tip>
  选项页适合批量管理与配置；日常翻译可在网页浮层中快速完成。
</Tip>
