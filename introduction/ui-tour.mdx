LayerAI surfaces different levels of action through three interfaces: the **browser popup**, the **extension options page**, and the **on-page overlay**:
1. The popup handles quick toggles and collection entry points for the current site;
2. The options page handles bulk management and global configuration;
3. The on-page overlay handles in-page translation editing.

## How the three interfaces divide work

| Interface | Entry | Best for |
| --- | --- | --- |
| **Browser popup** | Click the LayerAI toolbar icon | Current site status, auto-replace toggle, quick collect, replace mode |
| **Extension options page** | “Manage” at the bottom of the popup, or right-click the extension → **Options** | Per-site entries, queue, glossary, models, sync, and global settings |
| **On-page overlay** | Edge button / translation list on the page | Select to collect, edit entries, AI translate, and save on the current page |

Day-to-day reading mainly relies on **auto-replace**. When you need to revise wording or fill gaps, prefer the on-page overlay; for bulk work, open the options page.

## Browser popup

Click the LayerAI icon in the toolbar to open the popup. It always shows status and actions for the **site of the current tab**.

## On-page overlay

When you visit a page where the extension is enabled, LayerAI injects interactive elements into the page. These overlays work with the popup and options page: **after you start collection from the popup or options page, editing and saving usually happen in the overlay**.
