## Manage categories

- **Create category** — for example, “Product UI” or “Legal terms”
- **Activate** — only active categories participate in translation matching
- **Entries** — each entry includes a source term, target language, and translation

## Entry fields

| Field | Description |
| --- | --- |
| source_term | Source terminology |
| target_lang | Target language code |
| translation | Specified translation (leave empty to forbid translation) |

## Import and export

On the [Data sync](/sync/local-import-export) page, you can import or export glossary JSON separately.

For Free users, glossaries stay local only; Pro / Max can use [cloud sync](/glossary/sync).
