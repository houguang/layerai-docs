## 任务卡片信息

- 目标语言、使用模型
- 进度（已完成 / 总数）
- 成功 / 失败条数
- Token 消耗（如有）
- 创建 / 完成时间

## 常用操作

| 操作 | 说明 |
| --- | --- |
| **查看结果** | 打开成功/失败条目明细 |
| **重试失败** | 仅对失败字段重新入队 |
| **取消** | 停止进行中的任务 |
| **清理已完成** | 从列表移除历史任务 |

## 自动重试

平台模型任务可能触发自动重试，进度条会显示重试次数。持续失败请查看 [AI 错误排查](/troubleshooting/ai-errors)。
