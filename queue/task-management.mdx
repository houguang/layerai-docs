## Task card details

- Target language and model used
- Progress (completed / total)
- Success / failure counts
- Token usage (when available)
- Created / completed time

## Common actions

| Action | Description |
| --- | --- |
| **View results** | Open success/failure entry details |
| **Retry failed** | Re-queue only failed fields |
| **Cancel** | Stop a running job |
| **Clear completed** | Remove finished jobs from the list |

## Automatic retries

Platform-model jobs may retry automatically; the progress bar shows the retry count. If failures persist, see [AI error troubleshooting](/troubleshooting/ai-errors).
