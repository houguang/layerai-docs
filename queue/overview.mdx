翻译队列用于在后台批量执行 AI 翻译任务，避免大量待译字段阻塞页面操作。入口：扩展管理页 → **翻译队列**。

## 作用

将大量待翻译字段放入后台队列，按配置 **分片、并发、重试** 依次处理，避免阻塞页面操作。

## 任务来源

- 翻译管理 / 弹窗中发起的 **AI 一键翻译**
- 整站采集后的批量翻译

## 任务状态

| 状态 | 说明 |
| --- | --- |
| 排队中 | 等待执行 |
| 进行中 | 正在调用模型 |
| 已完成 | 全部成功或部分成功 |
| 失败 | 可手动或自动重试 |
| 已取消 | 用户主动取消 |
