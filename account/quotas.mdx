LayerAI 对平台模型 Token 与共享翻译下载次数按套餐分配额度，用户可在基础配置中查看当前用量。

## 查看位置

基础配置 → **账号** 模块。

## Token 额度

使用 **平台模型** 进行 AI 翻译时消耗 Token，按套餐分配：

- Free 模型池
- Pro 模型池
- Max 模型池

**自定义模型** 使用用户自有的 API 额度，不占用 Layer Token（除非走平台代理）。

## 共享下载配额

每月可下载共享翻译包的次数因套餐而异。配额用尽后需等待周期重置或升级套餐。

## 配额用尽时的处理方式

- Token 用尽 → 改用 [自定义模型](/models/custom-models) 或升级套餐
- 下载配额用尽 → 等待重置或使用已下载的包
