LayerAI offers Free, Pro, and Max plans. On top of local translation, each tier unlocks platform model quotas, cloud sync, shared translations, and other collaboration features.

## Plan overview

| Capability | Free | Pro | Max |
| --- | --- | --- | --- |
| Local capture and translation | ✓ | ✓ | ✓ |
| Custom AI models | ✓ | ✓ | ✓ |
| Platform model tokens | Basic | Higher | Highest |
| Layer Cloud sync | — | ✓ | ✓ |
| Shared translation downloads | Limited | Higher | Highest / unlimited |
| Glossary cloud sync | — | ✓ | ✓ |

Exact quotas follow the official [pricing page](https://local-layer.com/pricing).

## Upgrade

1. Visit the [subscription page](https://local-layer.com/subscription)
2. Choose Pro / Max monthly or yearly billing
3. After payment, the plan badge in the extension updates automatically (stay signed in)

## Downgrade

Cancel your subscription in the Customer Portal. Free entitlements resume after the current period ends. Local data is not deleted.
