## 系统要求

- Chromium 内核浏览器（Chrome、Edge、Brave 等）
- 允许扩展访问需要翻译的网站

## 安装步骤

<Steps>
  <Step title="获取扩展包">
    从 Chrome Web Store（上架后）或团队提供的 `.crx` / 开发者模式加载未打包扩展。
  </Step>
  <Step title="固定到工具栏">
    点击浏览器扩展图标 → 将 LayerAI **固定**到工具栏，便于随时打开弹窗。
  </Step>
  <Step title="授予站点权限">
    首次在某网站使用时，浏览器可能提示「读取和更改网站数据」——需允许后才能在页面上采集与替换。
  </Step>
  <Step title="打开选项页">
    建议安装后先进入 [基础设置](/quickstart/basic-settings)，配置目标语言与默认模型。
  </Step>
</Steps>

## 开发者模式加载（本地构建）

若从源码构建扩展：

```bash
cd extension
pnpm install
pnpm build
```

然后在浏览器中打开 `chrome://extensions` → 开启**开发者模式** → **加载已解压的扩展程序** → 选择 `extension/.output/chrome-mv3`（或构建输出目录）。

## 验证安装

1. 打开任意外文网页
2. 点击 LayerAI 图标，弹窗正常显示
3. 页面边缘出现「手动采集」悬浮按钮

若弹窗空白或页面无反应，参见 [故障排查](/troubleshooting)。
