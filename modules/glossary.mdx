The glossary constrains how terms are translated during AI translation—brand names and specialized vocabulary stay consistent. Entry point: options page → **Glossary**. Glossary matches take priority; unmatched content is AI-translated afterward.

</Frame>

| Type | Description |
| --- | --- |
| **Local glossary** | Categories and entries you create, stored in the browser |
| **Platform glossary** | Public terminology packs from Layer; browse and reference them |

## Local glossary

Maintain personal or project-level terms on the options page—no sign-in required.
