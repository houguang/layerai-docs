Page collection is the starting point of the LayerAI translation flow: extract source text from target pages and archive it by site. All methods **automatically skip content that already has translations**.

<Frame caption="Page collection overview">
  <video controls playsInline className="w-full aspect-video rounded-xl" src="/assets/videos/modules/collection-overview_zh.mp4" />
</Frame>

| Method | Entry point | Best for |
| --- | --- | --- |
| **Manual collection** | Floating button on the page | Precisely selecting a few elements |
| **Current page** | Popup → “Collect current page” | Single-page docs and articles |
| **Current site** | Popup → “Collect current site” | Batch collection across same-domain pages |

## Manual collection

Select elements on the page to add text for translation precisely—best for complex layouts or a small amount of UI copy.

<Frame caption="Manual collection">
  <img src="/assets/images/ui-tour/4_cn.gif" alt="Manual collection" />
</Frame>

<Steps>
  <Step title="Open the target page">
    Visit the page you want to translate.
  </Step>
  <Step title="Click the manual collection button">
    Click the floating **Manual collect** button at the page edge to enter selection mode.
  </Step>
  <Step title="Select elements">
    Hover to highlight elements, click to select; content is added to the translation list.
  </Step>
</Steps>

## Collect current page

Started from the extension popup; scans visible text in the current DOM. Good for single-page docs and articles.

<Frame caption="Popup → Collect current page">
  <img src="/assets/images/modules/1.gif" alt="Collect current page" />
</Frame>

<Steps>
  <Step title="Open the popup">
    Click the LayerAI toolbar icon.
  </Step>
  <Step title="One-click collect">
    Click **Collect current page**; the extension extracts visible text and skips already translated content.
  </Step>
  <Step title="Review results">
    After collection, review entries in the translation list popup or translation management.
  </Step>
</Steps>

## Collect current site

Follow same-domain links to collect multiple pages in batch—good for documentation sites and help centers.

<Frame caption="Options page · Translation management site list">
  <img src="/assets/images/modules/2.gif" alt="Translation management main area on the options page" />
</Frame>

<Tabs>
  <Tab title="When to use">
    Web tools, product docs, wikis, help centers, and other scenarios that need whole-site localization.
  </Tab>
  <Tab title="How">
    Extension popup → **Collect current site**; the extension follows same-domain links to continue collecting.
  </Tab>
  <Tab title="Note">
    For large whole-site jobs, use the [translation queue](/modules/queue) to run AI translation in the background.
  </Tab>
</Tabs>
