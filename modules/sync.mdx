## Sync method comparison

| Method | Sign-in required | Best for |
| --- | --- | --- |
| **Local import/export** | No | Manual backup, migration, version archives |
| **Layer cloud sync** | Yes (Pro / Max) | Automatic multi-device sync of translations and settings |
| **Google Drive** | No (authorization required) | Scheduled personal cloud JSON backups |
