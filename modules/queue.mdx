The translation queue handles AI batch translation jobs. It chunks work and calls models concurrently in the background so large batches do not block page interaction.

<Frame caption="Translation queue overview">
  <img src="/assets/images/modules/queue-overview_zh.png" alt="Translation queue with a completed job for tailwindcss.com" />
</Frame>

## Purpose

Put many pending entries into a background queue and process them with configured **chunking, concurrency, and retries**. Entry point: options page → **Translation queue**.

## Job sources

- **AI one-click translate** from Translation management or the on-page list
- Batch translation after whole-site collection

## Job status

| Status | Meaning |
| --- | --- |
| Queued | Waiting to run |
| Running | Calling the model |
| Completed | Fully or partially successful |
| Failed | Can be retried manually or automatically |
| Cancelled | Stopped by the user |

## Task management

View task details, failed items, retry, or cancel.

<Steps>
  <Step title="Check progress">
    In the queue list, view current progress and remaining entries.
  </Step>
  <Step title="Handle failures">
    Expand failure details; fix configuration using [AI error troubleshooting](/troubleshooting/ai-errors), then retry.
  </Step>
  <Step title="Cancel a task">
    In-progress tasks can be canceled; completed entries are still kept.
  </Step>
</Steps>

## How it connects to other modules

The queue depends on the default model and [runtime config](/models/runtime-config) in [Model configuration](/modules/models). After large [page collection](/modules/collection) jobs, prefer the queue over waiting entry by entry.
