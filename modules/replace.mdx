Page replace is the key to LayerAI’s “translate once, reuse while unchanged”: saved translations automatically replace source text on return visits—no re-translation.

## Auto-replace

Controls whether saved translations replace source text when you visit a page.

<Frame caption="Popup · Auto-replace toggle">
  <img src="/assets/images/ui-tour/2_cn.png" alt="Auto-replace toggle in the browser popup" />
</Frame>

<Tabs>
  <Tab title="On">
    Apply translations using the current replace mode when visiting pages—the main state for daily reading.
  </Tab>
  <Tab title="Off">
    Data stays saved, but the page still shows source text—useful for debugging or temporarily viewing the original.
  </Tab>
  <Tab title="Per site">
    You can also enable/disable whole-site replace per site in translation management.
  </Tab>
</Tabs>

## Replace modes

<Steps>
  <Step title="Exact replace (default)">
    Replaces text using the DOM locator from collection time. Suitable for most auto-collected entries.
  </Step>
  <Step title="Content-match replace">
    Finds and replaces by source content on the page. Suitable for reuse across pages or manually maintained general entries.
  </Step>
</Steps>

## How it connects to other modules

After [Page collection](/modules/collection) and [Translation management](/modules/translation) produce translations, this module applies them during reading. Turning off auto-replace does not affect saved data.
