## AI batch translation

Select entries to translate; the translation queue calls AI models in the background in order.

<Frame caption="AI one-click translate">
  <img src="/assets/images/ui-tour/6.gif" alt="AI one-click translate button" />
</Frame>
<Tip>
  You can start AI one-click translate from both the site list and the entry list. The difference: in the entry list you can select which entries to translate; from the site list, all untranslated entries are added to the translation queue.
</Tip>
<Steps>
  <Step title="Select entries">
    Select entries to translate in the popup or site details.
  </Step>
  <Step title="Start translation">
    Click **AI one-click translate**; the job is added to the [translation queue](/modules/queue).
  </Step>
  <Step title="Review results">
    After the queue finishes, check translations and fix terms with the [glossary](/modules/glossary) when needed.
  </Step>
</Steps>

<Card title="AI batch translation" icon="zap" href="/translation/ai-batch">

</Card>

## Submit shared translation

When a site reaches 100% translation progress and meets quality guidelines, you can submit the whole-site pack to the community.

<Frame caption="Submit shared entry (Translation management · site details)">
  <img src="/assets/images/modules/translation/submit-shared_zh.png" alt="Submit shared button and progress hint in site details" />
</Frame>

<Tabs>
  <Tab title="Submit requirements">
    Signed in to a Layer account; 100% translation progress; no large number of empty targets.
  </Tab>
  <Tab title="How">
    Translation management → select site → **Submit shared** → confirm.
  </Tab>
  <Tab title="Review status">
    In review / approved / rejected—view under Shared translations → My shares.
  </Tab>
</Tabs>

<Card title="Submit shared translation (reference)" icon="upload" href="/translation/submit-shared">
  Review flow and status details.
</Card>
