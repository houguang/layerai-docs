Model configuration determines which large model AI translation uses, how the API is called, and concurrency/retry strategy for batch translation. Entry point: options page → **Model configuration**.

<Frame caption="Model configuration overview">
  <img src="/assets/images/modules/4.png" alt="Model configuration overview" />
</Frame>

| Type | Description |
| --- | --- |
| **Platform models** | Official Layer models. Sign-in required; tokens follow your plan. |
| **Custom models** | OpenAI-compatible / Anthropic / Gemini / Ollama and similar APIs you configure |

Also configure the default model, [prompt templates](/models/prompts), and [runtime parameters](/models/runtime-config) (batching, concurrency, retries). Some platform models are Pro / Max only—see [Plans](/account/plans).

## Platform models

After signing in to a Layer account, use officially integrated models such as GPT, Claude, and Gemini. Token quotas are consumed according to your plan.

<Tabs>
  <Tab title="Best for">
    Users who do not want to configure their own API keys and prefer a ready-to-use setup.
  </Tab>
  <Tab title="Quotas">
    Free / Pro / Max have different Token quotas—see [Account & settings](/modules/account-settings).
  </Tab>
</Tabs>

## Custom models

Supports OpenAI-compatible APIs, Anthropic, Gemini, Ollama, and more. Data goes directly to your API provider.

<Steps>
  <Step title="Add a model">
    Add a custom model in model configuration; enter the Endpoint and API Key.
  </Step>
  <Step title="Set as default">
    Set your preferred model as default for AI one-click translate.
  </Step>
  <Step title="Test connection">
    Verify the API before saving to avoid batch failures in the queue.
  </Step>
</Steps>
