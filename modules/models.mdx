## 平台模型

登录 Layer 账号后可使用官方接入的 GPT、Claude、Gemini 等模型，按套餐消耗 Token 额度。

<Tabs>
  <Tab title="适用">
    不想自行配置 API Key、希望开箱即用的用户。
  </Tab>
  <Tab title="额度">
    Free / Pro / Max 各有不同 Token 配额，见 [账号与设置](/modules/account-settings)。
  </Tab>
</Tabs>

<Card title="平台模型" icon="sparkles" href="/models/platform-models">
  可用模型列表与额度说明。
</Card>

## 自定义模型

支持 OpenAI 兼容 API、Anthropic、Gemini、Ollama 等，数据直连你的 API 提供商。

<Steps>
  <Step title="添加模型">
    在模型配置中新增自定义模型，填写 Endpoint 与 API Key。
  </Step>
  <Step title="设为默认">
    将常用模型设为默认，AI 一键翻译时使用。
  </Step>
  <Step title="测试连接">
    保存前验证 API 可用，避免队列批量失败。
  </Step>
</Steps>
