When you collect a page or open a site that already has data, a draggable **translation list** modal appears on the page.

## Features

- Table of current-page entries (source / translation)
- Hover a row to highlight the matching element on the page
- Select rows and run **AI translate**
- **Save** to apply replacements immediately
- Per-entry **delete** and **enable/disable**

## Shortcuts

- Click column headers to sort; search source or translation text
- A toast confirms a successful save
- The AI translate button shows a loading state while a job runs
