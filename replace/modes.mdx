LayerAI provides two page replacement modes for applying saved translations on the page. Switch them from: extension popup → **Replacement mode**.

## Exact replacement

- Replaces text using the **DOM location (XPath)** captured at collection time
- Works with entries obtained through collection
- **Manually added** entries are not available in this mode

## Content-match replacement

- Searches the page DOM for text nodes that **match the source** and replaces them
- Good for reusing the same translation across pages
- Supports [manually added translations](/translation/edit-entries)

## How to choose

| Scenario | Recommended mode |
| --- | --- |
| Typical page localization | Exact |
| Same copy appears on many pages | Content match |
| Large sets of hand-maintained shared phrases | Content match |

<Tip>
  You can switch modes at any time; saved entry data is not affected.
</Tip>
