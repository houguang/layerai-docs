Auto-replace controls whether LayerAI replaces original text with saved translations when you visit a page.

## Where to toggle

Extension popup → **Auto-replace**.

## Behavior

| State | Effect |
| --- | --- |
| **On** | On visit, replace source text with translations (per the current replacement mode) |
| **Off** | Data is kept, but the page still shows the original text |

Turn auto-replace off when debugging translations or temporarily viewing the original page.

## Per-site control

In **Translation management**, you can also enable or disable replacement for an entire site.
