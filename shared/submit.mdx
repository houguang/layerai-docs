共享翻译的提交流程允许用户将已完成的整站翻译包发布至社区，供其他用户下载使用。

## 提交入口

[翻译管理](/translation/site-list) → 选择站点 → **提交共享**（进度 100%）。

或参考 [提交共享翻译](/translation/submit-shared)。

## 审核流程

```
提交 → 审核中 → 通过（发布）/ 拒绝
```

在 **我的共享** 视图中可查看状态与条目数。

## 质量建议

- 完整翻译，避免大量空行
- 术语与官方文档保持一致
- 不含违法、侵权内容

## 发布后

其他用户可在浏览列表中下载该翻译包；提交方亦可通过运营后台申请下架（如遇违规内容）。
