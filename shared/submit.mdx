## 提交入口

[翻译管理](/translation/site-list) → 选择站点 → **提交共享**（进度 100%）。

或参考 [提交共享翻译](/translation/submit-shared)。

## 审核流程

```
提交 → 审核中 → 通过（发布）/ 拒绝
```

在 **我的共享** 查看状态与条目数。

## 质量建议

- 完整翻译，避免大量空行
- 术语与官方文档一致
- 不含违法、侵权内容

## 发布后

其他用户可在浏览列表下载；你可在运营后台请求下架（如有违规）。
