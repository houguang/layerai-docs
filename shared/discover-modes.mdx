Shared translation discovery modes control how LayerAI detects and applies matching community translation packs when you visit a site. Configuration entry: Basic settings → **Shared translation settings**.

## Three modes

| Mode | Behavior |
| --- | --- |
| **Manual download** | A popup in the top-right of the page asks whether to download |
| **Automatic download** | Downloads and applies silently, with no popup |
| **Icon badge only** | Extension icon badge notifies you; download manually from the popup |

## Matching rules

Published shared packs are matched by the current visit **domain**. The best recommendation is chosen (by entry count, language, and similar signals).

## Popup shortcuts

When a pack is available to download, the browser popup shows a **Shared translations** section for one-click download.
