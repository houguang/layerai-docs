选项页 → **共享翻译**。

## 是什么

用户将整站翻译包 **提交审核** 后发布到社区，其他人可 **下载** 到本地使用，形成可复用的翻译资产。

## 两个视图

| 视图 | 说明 |
| --- | --- |
| **浏览** | 发现各域名下的公开翻译包 |
| **我的共享** | 查看自己提交的记录与审核状态 |

## 互动

- **下载** — 导入本地翻译库
- **点赞** — 需先下载该包
- **撤回下载** — 释放配额并移除关联
