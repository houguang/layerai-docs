## 欢迎使用 LayerAI

LayerAI 是一款**本地优先**的浏览器扩展，帮助你在网页内完成：

- **采集** — 从当前页面或整站抓取待翻译文本
- **翻译** — AI 批量翻译或手动精修
- **替换** — 保存后立即生效，再次访问自动应用
- **治理** — 词库约束术语，队列管理批量任务
- **协作** — 云同步、共享翻译下载与提交

## 核心概念

| 概念 | 说明 |
| --- | --- |
| **站点** | 按域名（如 `example.com`）组织的翻译集合 |
| **词条** | 一条原文及其各目标语言的译文，绑定页面元素定位信息 |
| **精确替换** | 按 DOM 定位精确替换已采集的文本 |
| **内容匹配替换** | 按文本内容匹配替换，适合手动添加的通用译文 |
| **翻译队列** | 后台批量执行 AI 翻译任务，支持进度追踪与重试 |
