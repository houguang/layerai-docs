## Export file structure

Local export JSON typically includes:

```json
{
  "version": "1.x",
  "exportTime": "ISO-8601 timestamp",
  "translationGroups": [],
  "aiConfig": {},
  "aiTranslateRuntimeConfig": {},
  "customModels": [],
  "promptConfig": {}
}
```

## translationGroups

Each site object:

| Field | Description |
| --- | --- |
| url | Site domain identifier |
| enabled | Whether replacement is enabled |
| replacementMode | `exact` or `content_match` |
| items | Array of entries |
| sharedSourceId | ID from a shared pack (optional) |

## items entries

| Field | Description |
| --- | --- |
| id | Unique ID |
| source | Source text |
| target | Shape of `{ "zh-CN": "translation" }` |
| locator | `{ "xpaths": ["..."] }` |
| enabled | Whether enabled |
| variablePattern | Placeholder pattern (if any) |

## Placeholders

AI translation preserves this format:

```
{{@identifier#index|source text}}
```

On output, only the text after the pipe `|` is translated; the rest of the structure stays unchanged.

## Glossary export

Glossaries can be exported separately. The structure includes a `categories` array, and each category contains an `entries` list. See [Local glossary](/glossary/local-glossary).

<Warning>
  Export files may contain API Keys. Redact them before sharing.
</Warning>
