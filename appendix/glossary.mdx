| Term | Also known as | Description |

| Site | Site / Translation Group | A translation set organized by domain |
| Entry | Item / Entry | A source string and its translation |
| Locator | Locator | DOM location info such as XPath |
| Exact replacement | Exact replacement | Replace by locator |
| Content match | Content match | Replace by matching the source text |
| Glossary | Glossary | Term constraint table |
| Translation queue | Translation queue | Batch AI task queue |
| Shared translation | Shared translation | Community-published translation pack |
| Platform model | Platform model | AI model provided by Layer |
| Custom model | Custom model | Model configured with the user's own API |
