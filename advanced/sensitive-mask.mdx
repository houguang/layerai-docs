Developer settings → **Sensitive data masking**.

## Purpose

Before calling AI translation, mask text that matches configured regex rules (for example phone numbers or email addresses) to reduce the risk of leaking data to third-party models.

## Configuration

- **Toggle** — Enable / disable
- **Rule list** — One regex per line, with an optional rule name

## Examples

```
Phone|\d{11}
Email|[\w.-]+@[\w.-]+\.\w+
```

## Notes

- Masking only affects **content sent to AI**; local storage still keeps the original text (unless the translation result itself changes it)
- Complex regex can affect performance; add rules carefully

## Restore defaults

You can restore the built-in rule set in one click.
