</Note>

At the bottom of the extension management page sidebar → **Developer settings** (bug icon next to the gear).

## Debug logs

When enabled, the browser console prints logs with the `[LocalLayer]` prefix, which helps investigate collection, replacement, sharing, and related issues.

When submitting feedback, you can attach relevant logs (redact sensitive data).

## Advanced options

- [Protected HTML tags](/advanced/protected-tags)
- [Sensitive data masking](/advanced/sensitive-mask)

## Intended audience

For technical users familiar with the DOM and regular expressions. Most users do not need to change the defaults.
