<Note>
  建议先阅读 [账号与设置模块概览](/modules/account-settings)，再查看本页细节。
</Note>

开发者配置 → **受保护标签**。

## 作用

采集文本时，某些内联标签（如 `code`、`kbd`）内的内容应与外层一起处理，避免 DOM 结构被拆碎导致替换失败。

## 配置格式

每行一个标签名（小写），例如：

```
code
kbd
span
```

## 默认值

扩展内置常用内联标签列表，一般无需修改。仅当特殊站点结构异常时调整。

## 恢复默认

点击 **恢复默认值** 还原出厂列表。
