Developer settings → **Protected tags**.

## Purpose

When collecting text, content inside certain inline tags (such as `code` or `kbd`) should be handled together with the surrounding text so the DOM structure is not broken in a way that causes replacement to fail.

## Configuration format

One tag name per line (lowercase), for example:

```
code
kbd
span
```

## Defaults

The extension ships with a list of common inline tags. You usually do not need to change it. Adjust only when a site has an unusual structure.

## Restore defaults

Click **Restore defaults** to reset to the factory list.
