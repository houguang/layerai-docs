## Enable / disable

A disabled entry **does not participate in page replacement**, but the data is kept and can be re-enabled at any time.

In the translation list modal, use the toggle to control each entry.

## Delete

After you delete an entry, the page shows the original text again at that location (if auto-replace is on and no other rule matches).

<Warning>
  Deletion cannot be undone. [Export a backup](/sync/local-import-export) first.
</Warning>
