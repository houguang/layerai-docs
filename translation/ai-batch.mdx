AI batch translation lets you select multiple pending entries at once. The extension calls the AI model in a background queue and writes results back.

## Where to start

- On-page **translation list modal** → AI translate
- **Translation management** site details → select entries → AI translate

## Prerequisites

- A default model is set in [Model configuration](/modules/models)
- Custom models need a valid API key and endpoint
- Platform models require sign-in and enough token quota

## How it runs

1. Selected fields are added to the [translation queue](/modules/queue)
2. The background worker chunks, runs concurrently, and retries per [runtime configuration](/models/runtime-config)
3. Results are written back to entries; open the queue page for details

## Error handling

See [AI error troubleshooting](/troubleshooting/ai-errors) for common failures.
