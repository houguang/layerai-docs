---
title: 提交共享翻译
description: 将站点翻译包提交到社区供他人下载。
icon: "upload"
---

<Note>
  建议先阅读 [翻译管理模块概览](/modules/translation)，再查看本页细节。
</Note>

## 提交条件

- 已 [登录 Layer 账号](/journey/login)
- 该站点翻译进度达到 **100%**
- 词条质量符合社区规范（无大量空译文）

## 操作步骤

翻译管理 → 选择站点 → **提交共享** → 确认。

提交后进入审核流程，可在 **共享翻译 → 我的共享** 查看状态：

| 状态 | 说明 |
| --- | --- |
| 审核中 | 等待运营审核 |
| 已通过 | 发布到浏览列表 |
| 已拒绝 | 查看原因后修改再提交 |
