Translation management is LayerAI’s core data module. It organizes all translation entries by site and supports search, batch actions, and AI translation. Entry point: extension management page → **Translation management**.

The list is grouped by **domain (site)**; click a site to open its details.

## Site list

Each site card shows:

- Domain / URL identifier
- Entry count and translation progress
- Whether replacement is enabled for the site
- Shared-source badge (if downloaded from a shared pack)

## Site details

- Search source or translation text
- Select entries for batch actions
- **AI translate** selected entries
- **Submit to shared** (available when progress is 100%)
- Open the [manual translation](/translation/manual-translation) workflow
