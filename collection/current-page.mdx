## Steps

Extension popup → **Collect current page**.

The extension scans the current DOM, extracts visible text nodes, and creates entries awaiting translation.

## Behavior

- Text that already has a translation is skipped
- Results appear in the translation list modal or **Translation management**
- Best for single-page articles, landing pages, and doc pages

## Difference from site-wide collection

Current page handles **only the current URL** and does not follow links. For multi-page sites, use [Collect current site](/collection/current-site).
