## Steps

Extension popup → **Collect current site**.

The extension extracts **same-domain links** from the current page, then opens and collects translatable text from each page in turn.

## When to use it

- Multi-page product docs, help centers, and marketing sites
- Building a full-site translation asset in one pass

## Notes

- Large site-wide jobs take longer; pair them with the [translation queue](/modules/queue) for batch AI translation
- Dynamic SPAs may need multiple passes or manual collection to fill gaps
- See also [Collection rules](/collection/rules)
