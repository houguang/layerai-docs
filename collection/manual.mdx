Manual collection lets you select elements one by one on the page to add text for translation. Use it when automatic collection cannot target the content you need.

## How to start

1. Open the target web page.
2. Click the **Manual collection** floating button at the page edge.
3. Hover to highlight an element, then click to select it.
4. Selected content is added to the translation list.
5. Hold <code>ALT</code> to temporarily disable collection and use the page’s original interactions. For example, if a menu only appears after a click, hold <code>ALT</code>, open the menu, then release <code>ALT</code> to resume collection.

## When to use it

- Complex layouts where auto-collection picks up too much noise
- Only a few UI strings (nav, buttons) need translation
- Dynamically loaded regions that need human confirmation

## Tip

Entries from manual collection include DOM location data and work well with [Exact replacement](/replace/modes).
