# LayerAI Documentation

LayerAI is a **local-first** browser extension that helps users collect page text, run AI translation, govern terminology, and apply multilingual replacements on the web. Unlike tools that re-translate every page load, LayerAI turns translations into reusable assets: when the same page content has not changed, confirmed wording applies automatically.

- **Live docs**: https://docs.layerai.yun

The source language for this repository is **English**. Other language versions can be generated by translating the docs site with the LayerAI extension itself.

## Product positioning

LayerAI upgrades fragmented foreign-language web reading into a **collaborative translation workflow**:

- **Collect** — Extract text from the current page, whole site, or a selected range
- **Translate** — Multiple AI models with glossary constraints; queued execution with retries
- **Replace** — Automatically apply saved translations on the original page
- **Govern** — Glossaries and shared translation submit/review for consistent wording
- **Sync** — Local import/export; Pro / Max users can use Layer cloud sync and Google Drive backup

The Free plan is enough to validate the flow; Pro / Max add higher quotas, collaboration, and sync. Website and subscription: [layerai.yun](https://layerai.yun).
