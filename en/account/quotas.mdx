LayerAI allocates platform model tokens and shared translation download counts by plan. Current usage is shown in Basic Settings.

## Where to View

Basic Settings → **Account** section.

## Token Allowance

**Platform models** consume tokens during AI translation, allocated by plan:

- Free model pool
- Pro model pool
- Max model pool

**Custom models** use the user's own API quota and do not consume Layer tokens (unless routed through a platform proxy).

## Shared Download Quota

The number of shared translation packages that can be downloaded per month varies by plan. When the quota is exhausted, the user must wait for the period to reset or upgrade the plan.

## When Quotas Are Exhausted

- Tokens exhausted → switch to a [custom model](/en/models/custom-models) or upgrade the plan
- Download quota exhausted → wait for reset or use already downloaded packages
