LayerAI offers Free, Pro, and Max tiers. On top of local translation capabilities, each tier unlocks platform model quotas, cloud sync, and shared translation collaboration at different levels.

## Plan Overview

| Capability | Free | Pro | Max |
| --- | --- | --- | --- |
| Local collection and translation | ✓ | ✓ | ✓ |
| Custom AI models | ✓ | ✓ | ✓ |
| Platform model tokens | Basic | Higher | Highest |
| Layer cloud sync | — | ✓ | ✓ |
| Shared translation downloads | Limited | Higher | Highest / Unlimited |
| Glossary cloud sync | — | ✓ | ✓ |

Specific quotas are listed on the official [pricing page](https://local-layer.com/pricing).

## Upgrade

1. Visit the [subscription page](https://local-layer.com/subscription)
2. Select Pro or Max (monthly or annual billing)
3. After payment completes, the plan badge in the extension updates automatically (requires an active sign-in)

## Downgrade

Subscriptions can be cancelled in Customer Portal. Free-tier benefits resume after the current billing period ends. Local data is not deleted.
