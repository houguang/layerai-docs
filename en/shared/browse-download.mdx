## Browse List

Shared Translations → **Browse** — view published packs by domain, language, entry count, and other filters.

## Download

When **Download** is clicked:

- If there is **no** local site for that domain → a new site is created directly
- If a site **already exists** → a merge dialog appears (merge or overwrite strategy)

## Download Quota

Free, Pro, and Max plans have different **monthly download limits**. See [Account Quotas](/en/account/quotas).

When quota is exhausted, the UI shows when it resets.

## In-Page Quick Download

While visiting a site, the extension may prompt that a shared pack is available. See [Discovery Modes](/en/shared/discover-modes) for details.
