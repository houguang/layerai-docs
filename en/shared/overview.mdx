Shared Translations is LayerAI's community collaboration feature: users submit whole-site translation packs for review and publication to the community; other users download them for local use, building reusable translation assets. Access it from the options page → **Shared Translations**.

## How It Works

After a whole-site translation pack is **submitted for review** and published to the community, other users can **download** it into their local translation library as a reusable asset.

## Two Views

| View | Description |
| --- | --- |
| **Browse** | Discover public translation packs by domain |
| **My Shares** | View submission history and review status |

## Interactions

- **Download** — Import into the local translation library
- **Like** — Requires downloading the pack first
- **Revoke download** — Frees quota and removes the association
