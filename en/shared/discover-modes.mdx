Discovery modes control how LayerAI detects and applies matching community translation packs when a user visits a site. Configure them in Basic Settings → **Shared Translation Settings**.

## Three Modes

| Mode | Behavior |
| --- | --- |
| **Manual download** | A popup in the page corner asks whether to download |
| **Automatic download** | Downloads and applies silently with no popup |
| **Icon badge only** | Extension icon badge indicates availability; download manually from the popup |

## Matching Rules

Matches published shared packs by the **domain** of the current page and selects the best recommendation (entry count, language, etc.).

## Popup Shortcuts

When a pack is available for download, the browser popup shows a **Shared Translations** section with one-click download.
