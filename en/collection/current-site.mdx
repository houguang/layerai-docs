## Steps

Extension popup → **Collect current site**.

The extension extracts **same-domain links** from the current page, opens each linked page in turn, and collects translatable text.

## When to use

- Multi-page translation for product docs, help centers, or marketing sites
- Building a full-site translation asset in one pass

## Notes

- Large whole-site runs can take a long time; pairing with the [translation queue](/en/queue/overview) for batch AI translation is recommended
- Dynamic SPA sites may require multiple collection passes or [manual collection](/en/collection/manual) to fill gaps
- See [Collection rules](/en/collection/rules) for details
