## Steps

Extension popup → **Collect current page**.

The extension scans the current DOM, extracts visible text nodes, and creates pending translation entries.

## Behavior

- Text that already has a translation is skipped
- Results appear in the translation list popup or under **Translation management**
- Best for single-page articles, landing pages, and documentation pages

## vs. whole-site collection

Current page **only processes the current URL** and does not follow links. For multi-page sites, use [Collect current site](/en/collection/current-site).
