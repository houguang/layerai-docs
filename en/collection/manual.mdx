Manual collection allows users to select individual elements on the page for translation. It suits scenarios where automatic collection cannot locate content precisely.

## Getting started

1. Open the target page
2. Click the **Manual collection** floating button on the page edge
3. Hover to highlight elements, then click to select
4. Selected content is added to the translation list

While collection is active, the button shows **Collecting manually**; clicking again exits the mode.

## When to use

- Complex page structure where automatic collection would capture extra content
- Translating only a few UI strings such as navigation or buttons
- Dynamically loaded regions that require manual confirmation

## Tips

Entries collected manually include DOM locator data and work with [Exact replace](/en/replace/modes) mode.
