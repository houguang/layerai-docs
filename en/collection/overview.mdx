Web collection is the starting point of the LayerAI translation workflow. The extension offers three collection methods; each **automatically skips content that is already translated**.

| Method | Entry | Best for |
| --- | --- | --- |
| **Manual collection** | Floating button on the page | Precisely selecting a small number of elements |
| **Current page** | Popup → **Collect current page** | Single-page docs and articles |
| **Current site** | Popup → **Collect current site** | Batch collection across same-domain pages |

## Choosing a method

- **Single-page content** → Current page
- **Product docs, help centers** → Current site (follows same-domain links)
- **Editing a few elements** → Manual collection
