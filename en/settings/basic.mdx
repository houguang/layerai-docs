The Basic Settings module centralizes UI language, translation target language, theme appearance, and account information. Entry point: options page → **Basic Settings**.

## General Settings

| Item | Description |
| --- | --- |
| UI language | Extension interface language |
| Target language | Language key for translated text (e.g. `zh-CN`) |
| Theme | Light / dark / system |

For a quick start, see [Basic Settings](/en/quickstart/basic-settings).

## Account

Sign-in, plan, token, and shared download usage. See [Sign-in and Account](/en/account/login).

## Feedback

The bottom of the settings page offers a QR code to join the community group or submit feedback (as shown in the UI).
