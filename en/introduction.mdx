LayerAI is a local-first browser extension that turns foreign-language web pages from "re-translate on every visit" into a **translate once, persist forever** controllable content layer. The extension runs locally in the user's browser; translation data is stored on the device by default, and core features do not require account registration. On any web page, users can collect text, translate with AI or manually, and replace page content in real time.

## What LayerAI Solves

When users revisit the same foreign-language sites, they often need to call AI repeatedly, wait for results, and lose confirmed translations. Teams also struggle to align terminology. LayerAI connects the full workflow—**collect → translate → save → auto-replace**—within the page. Glossary constraints and a translation queue for batch tasks turn scattered translation work into a reusable, collaborative workflow.

## Supported Browsers and Models

LayerAI is built on the Chromium extension platform and supports multiple AI translation backends:

| Type | Description |
| --- | --- |
| **Chrome / Edge** | Install from the [Chrome Web Store](https://chromewebstore.google.com/detail/local-layer-interface-loc/ehhgbbhlookhlindmdkafmekmgkoilfl) |
| **Platform models** | After signing in with a Layer account, users can use officially integrated GPT, Claude, Gemini, and other models |
| **Custom models** | Supports OpenAI-compatible APIs, Anthropic, Gemini, Ollama, and more—see [Model Configuration](/en/models/overview) |
| **Prompts & glossaries** | Custom translation prompts; local/platform glossaries constrain terminology during AI translation |

## Privacy and Data

<Note>
  LayerAI is designed local-first. Translation data is stored in the browser by default; core capabilities do not depend on an account. The extension does not use visited page content for model training.

  After sign-in, users can enable cloud sync and shared translations for collaboration. Site read/write permissions are requested only when needed for collection and page replacement; users can revoke them anytime in browser extension settings. Backups can be configured via [local import/export](/en/sync/local-import-export) or [Google Drive](/en/sync/google-drive), with data flow under the user's control.
</Note>

## Use Cases

LayerAI serves individuals and teams who need long-term, high-quality web translation:

- **Reading foreign-language sites** — News, blogs, technical docs, and more; translate once and persist
- **Product localization** — Help centers, marketing pages, whole-site collection, and batch AI translation
- **Team collaboration** — Unify terminology via glossaries; reuse community translations through shared packages
- **Long-lived operational systems** — ERP, admin consoles, and other interfaces visited repeatedly
- **Independent developers** — Custom model integration for Token cost control and translation quality
