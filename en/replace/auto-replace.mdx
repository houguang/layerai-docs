Auto replace controls whether LayerAI replaces source text with saved translations when users visit a page.

## Where to toggle

Extension popup → **Auto replace**.

## Behavior

| State | Effect |
| --- | --- |
| **On** | Saved translations replace source text on visit (per the current replace mode) |
| **Off** | Data is saved only; the page still shows source text |

Turning auto replace off suits debugging translations or temporarily viewing source text.

## Per-site control

In **Translation management**, replace can also be enabled or disabled for an entire site.
