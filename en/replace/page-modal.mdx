When content is collected or an existing site is opened, a draggable **Translation list** popup appears on the page.

## Features

- Table of entries on the current page (source / target)
- Row hover highlights the matching element on the page
- Select entries and run **AI translate**
- **Save** applies replace immediately
- Per-entry **delete** and **enable/disable**

## Shortcuts

- Click column headers to sort; search source or target text
- A toast confirms successful save
- The AI translate button shows a loading state while work is in progress
