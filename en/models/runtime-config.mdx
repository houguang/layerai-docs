Model Configuration → **Runtime Parameters** (or translation-related advanced settings).

## Parameter Reference

| Parameter | Purpose | Recommendation |
| --- | --- | --- |
| **Batch size (batchSize)** | Number of entries per API request | Too large may exceed token limits; too small increases request count |
| **Concurrency** | Number of simultaneous requests | Adjust according to API rate limits |
| **Retry count (retryCount)** | Retries after a batch slice fails | Increase when the network is unstable |

## Relationship to the Queue

These parameters apply to batch tasks in the [translation queue](/en/queue/overview) and do not affect single-entry manual edits.

## Troubleshooting

Frequent timeouts or HTTP 429 rate limiting → reduce concurrency or batch size. See [AI Error Troubleshooting](/en/troubleshooting/ai-errors).
