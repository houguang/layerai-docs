The model configuration module manages the model sources and runtime parameters used for AI translation. Access it from the options page → **Model Configuration**.

## Two Model Types

| Type | Description |
| --- | --- |
| **Platform models** | Models provided by Layer; requires sign-in; Token allocation depends on the subscription plan |
| **Custom models** | User-configured OpenAI-compatible, Anthropic, Gemini, Ollama, and similar services |

## Configuration Options

- Default model selection
- API keys and endpoints for each platform
- [Prompt templates](/en/models/prompts)
- [Runtime parameters](/en/models/runtime-config) (batch size, concurrency, retries)

## Plan Restrictions

Some platform models are labeled with `Pro` / `Max` requirements and are not available on the Free plan. See [Plans](/en/account/plans) for details.
