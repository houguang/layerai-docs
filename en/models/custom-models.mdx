## Supported Platforms

| Platform | Description |
| --- | --- |
| **OpenAI-compatible** | OpenAI, Azure, and various proxy APIs |
| **Anthropic** | Claude series |
| **Gemini** | Google Gemini API |
| **Ollama** | Locally hosted open-source models |

## Configuration Steps

<Steps>
  <Step title="Add a custom model">
    Model Configuration → Add Model → enter name, platform, and model ID
  </Step>
  <Step title="Enter credentials">
    API key and endpoint (for Ollama, use a local address such as `http://127.0.0.1:11434`)
  </Step>
  <Step title="Set as default">
    Select the model from the default model dropdown
  </Step>
  <Step title="Test translation">
    Run a small AI translation on any page to verify the setup
  </Step>
</Steps>

<Warning>
  API keys are stored locally in the browser. Users should not configure production keys on shared or public devices.
</Warning>

## Local Ollama Deployment

Ensure the Ollama service is running and that the browser can reach the configured port. For CORS or mixed content issues, see [AI Error Troubleshooting](/en/troubleshooting/ai-errors).
