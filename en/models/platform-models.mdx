## Requirements

- [Sign in to a Layer account](/en/quickstart/login)
- Sufficient account Token balance

## Selecting a Model

On the Model Configuration page → **Default Model** → choose a model marked with the Platform badge.

## Viewing Quotas

On Basic Settings → **Account**, users can view:

- Free model Tokens
- Pro model Tokens
- Max model Tokens

Quotas reset according to the subscription plan and billing cycle. See [Quotas](/en/account/quotas) for details.

## Failures

When quota is exhausted or a model is unavailable, AI translation fails. Users can switch to a [custom model](/en/models/custom-models) or upgrade the subscription plan.
