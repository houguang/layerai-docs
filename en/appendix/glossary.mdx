| Term | English | Description |
| --- | --- | --- |
| Site | Site / Translation Group | Translation collection organized by domain |
| Entry | Item / Entry | One source string and its translation(s) |
| Locator | Locator | DOM location info such as XPath |
| Exact replacement | Exact replacement | Replace by DOM locator |
| Content match | Content match | Replace by matching source text |
| Glossary | Glossary | Terminology constraint table |
| Translation queue | Translation queue | Batch AI task queue |
| Shared translation | Shared translation | Community-published translation package |
| Platform model | Platform model | AI model provided by Layer |
| Custom model | Custom model | Model configured with the user's own API |
