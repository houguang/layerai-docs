## Task card fields

- Target language and model used
- Progress (completed / total)
- Success and failure counts
- Token usage (when available)
- Created and completed times

## Common actions

| Action | Description |
| --- | --- |
| **View results** | Open success/failure entry details |
| **Retry failed** | Re-queue only failed fields |
| **Cancel** | Stop an in-progress task |
| **Clear completed** | Remove finished tasks from the list |

## Automatic retry

Platform model tasks may trigger automatic retries; the progress bar shows retry count. For persistent failures, see [AI error troubleshooting](/en/troubleshooting/ai-errors).
