This page walks through LayerAI's most common end-to-end workflow: collect text from a web page, translate with AI, save, and auto-replace on the page.

## Prerequisites

- [Extension installed](/en/quickstart/install)
- Default model selected in [Model Configuration](/en/models/overview) and API Key configured (if using a custom model)

## Steps

<Steps>
  <Step title="Open target page">
    For example, an English product doc or blog article.
  </Step>
  <Step title="Collect current page">
    Click the extension icon → **Collect current page**. The extension captures visible text and skips already translated content.
  </Step>
  <Step title="Open translation list">
    After collection, a translation list panel appears on the page (or users can open the management page from the popup to view site entries).
  </Step>
  <Step title="AI one-click translate">
    In the panel, select entries to translate → click **AI one-click translate** and wait for the queue to finish.
  </Step>
  <Step title="Save">
    After confirming translations, click **Save**. Source text on the page is replaced immediately.
  </Step>
  <Step title="Verify persistence">
    Refresh the page or reopen the tab—translations should apply automatically (**Auto-replace** must be enabled).
  </Step>
</Steps>

## Popup Quick Toggles

| Toggle | Effect |
| --- | --- |
| **Auto-replace** | When off, translations are saved but not shown on the page |
| **Replacement mode** | Exact replacement (default) or content-match replacement |

## FAQ

<AccordionGroup>
  <Accordion title="AI translate button grayed out or errors">
    Check that [Model Configuration](/en/models/overview) is complete; see [AI Error Troubleshooting](/en/troubleshooting/ai-errors).
  </Accordion>
  <Accordion title="No change on page after save">
    Confirm **Auto-replace** is enabled and the entry is not disabled.
  </Accordion>
  <Accordion title="Translate whole site, not just current page">
    Use [Collect current site](/en/collection/current-site).
  </Accordion>
</AccordionGroup>
