The basic settings module configures the extension's UI language, translation target language, theme, and default AI model. It is the first configuration step after installation.

## Open Basic Settings

Extension popup → **Manage** → sidebar **Basic settings**, or open the options page directly.

## Recommended First-Time Configuration

| Setting | Description | Recommendation |
| --- | --- | --- |
| **UI language** | Language for extension UI | Choose a language the user is comfortable with |
| **Target language** | Language key for stored translations | e.g. `zh-CN` (Simplified Chinese) |
| **Theme** | Light / dark / follow system | Personal preference |
| **Default model** | Model used for AI translation | Requires API setup in [Model Configuration](/en/models/overview) first |

<Warning>
  Changing the target language does not automatically re-translate existing entries; it only affects the language field for new entries or AI translation going forward.
</Warning>

## Shared Translation Discovery (Optional)

Basic settings define how matching shared translations are handled when visiting a site:

- **Manual download** — Prompt in an in-page popup
- **Auto download** — Silently download and apply
- **Icon badge only** — Badge on the extension icon; download manually from the popup

See [Shared Translation Discovery](/en/shared/discover-modes) for details.
