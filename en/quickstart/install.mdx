LayerAI is built on the Chromium extension platform and supports Chrome, Edge, Brave, and similar browsers. After installation, the extension can collect text and replace content on target web pages.

## System Requirements

- Chromium-based browser (Chrome, Edge, Brave, etc.)
- Target sites must grant the extension access permissions

## Installation Steps

<Steps>
  <Step title="Obtain the extension">
    Install from the Chrome Web Store or a team-provided `.crx` package; alternatively, load an unpacked extension in developer mode.
  </Step>
  <Step title="Pin to toolbar">
    In the browser extensions menu, **pin** LayerAI to the toolbar for quick access to the popup.
  </Step>
  <Step title="Grant site permissions">
    On first use on a site, the browser may prompt to "Read and change site data"—permissions are required for collection and replacement on the page.
  </Step>
  <Step title="Open options page">
    After installation, users should open [Basic Settings](/en/quickstart/basic-settings) to configure target language and default model.
  </Step>
</Steps>

## Developer Mode (Local Build)

When building the extension from source:

```bash
cd extension
pnpm install
pnpm build
```

Then open `chrome://extensions` in the browser → enable **Developer mode** → **Load unpacked** → select `extension/.output/chrome-mv3` (or the actual build output directory).

## Verify Installation

After installation, users can confirm the extension works by:

1. Opening any foreign-language web page
2. Clicking the LayerAI icon—the popup should display normally
3. Checking for the "Manual collection" floating button at the page edge

If the popup is blank or the page does not respond, see [Troubleshooting](/en/troubleshooting/index).
