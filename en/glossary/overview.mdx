The glossary module constrains term translations during AI translation to keep brand names and specialized vocabulary consistent. Access it from the options page → **Glossary Management**.

## Why a Glossary Is Needed

The same source-language word may have multiple valid translations depending on context. A glossary lets AI **prefer preset translations**, for example:

- Product names left untranslated or mapped to a single approved translation
- Technical terms kept consistent across the site

## Glossary Types

| Type | Description |
| --- | --- |
| **Local glossary** | Categories and entries created by the user, stored locally in the browser |
| **Platform glossary** | Public term packs provided by Layer; browseable and referenceable |
