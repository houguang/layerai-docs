## Managing Categories

- **New category** — e.g. "Product UI", "Legal terms"
- **Activation** — Only active categories participate in translation matching
- **Entries** — Each entry includes source term, target language, and translation

## Entry Fields

| Field | Description |
| --- | --- |
| source_term | Source-language term |
| target_lang | Target language code |
| translation | Specified translation (empty means do not translate) |

## Import and Export

On the [Data Sync](/en/sync/local-import-export) page, users can import or export glossary JSON separately.

Free-plan glossaries are local only; Pro / Max users can use [cloud sync](/en/glossary/sync).
