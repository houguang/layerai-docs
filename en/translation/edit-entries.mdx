## How to edit

- **Translation list popup on the page** — Quick edits for a few entries on the current page
- **Translation management → site details** — Edit the target column directly in the table
- **Edit dialog** — Open the full editor by clicking an entry

## Enable / disable

When disabled, an entry **does not participate in page replace**, but the data is kept and can be re-enabled at any time.

In the translation list popup, each entry can be toggled on or off individually.

## Delete

After an entry is deleted, the corresponding location on the page shows the source text again (when auto replace is on and no other rule matches).

<Warning>
  Deletion cannot be undone. Users should [export a backup](/en/sync/local-import-export) first.
</Warning>
