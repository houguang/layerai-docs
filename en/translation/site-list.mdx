Translation management is LayerAI's core data module. It organizes all translation entries by site and supports search, bulk actions, and AI translation. Entry point: options page → **Translation management**.

The list is grouped by **domain (site)**; users open a site to view its details.

## Site list

Each site card shows:

- Domain / URL identifier
- Entry count and translation progress
- Whether site-wide replace is enabled
- Shared source badge (if downloaded from a shared package)

## Site details

- Search source or target text
- Select entries for bulk actions
- **AI translate** selected entries in one click
- **Submit to shared** (available at 100% progress)
- Open the [manual translation](/en/translation/manual-translation) workflow
