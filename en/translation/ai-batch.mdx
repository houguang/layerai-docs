AI batch translation lets users select multiple pending entries at once; the extension calls the AI model in a background queue to translate them sequentially.

## Where to trigger

- **Translation list popup** on the page → AI translate
- **Translation management** site details → select entries → AI translate

## Prerequisites

- A default model is set under [Model configuration](/en/models/overview)
- Custom models need a valid API key and endpoint
- Platform models require login and sufficient token quota

## Execution flow

1. Selected pending fields are added to the [translation queue](/en/queue/overview)
2. The background worker shards, runs concurrently, and retries per [runtime configuration](/en/models/runtime-config)
3. Results are written back to entries when complete; details are available on the queue page

## Error handling

Common errors are covered in [AI error troubleshooting](/en/troubleshooting/ai-errors).
