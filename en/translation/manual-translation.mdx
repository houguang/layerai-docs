This workflow suits users who want **full control over the AI process**: call ChatGPT, Claude, or similar tools externally, then paste results back into the extension.

## Workflow

<Steps>
  <Step title="Open manual translation">
    Translation management → select a site → Manual translation
  </Step>
  <Step title="Set chunk size">
    Split pending JSON by entry count to avoid overly long prompts
  </Step>
  <Step title="Copy prompt + chunk">
    Copy the system prompt and current chunk JSON in one click
  </Step>
  <Step title="Translate in external AI">
    Paste the copied content into any AI chat and obtain JSON results
  </Step>
  <Step title="Paste and save">
    Return to the extension, paste the translation JSON → **Paste and save**
  </Step>
</Steps>

## Notes

- Manually added entries (not from DOM collection) mainly apply under [Content match replace](/en/replace/modes)
- Chunk JSON structure must match the export format or validation will fail
