Local import and export lets users back up or migrate translation data, AI configuration, and glossaries as JSON without relying on cloud services. Access it from the options page → **Import/Export**.

## Export

Users can export **translation sites, AI configuration, custom models, prompts, glossaries**, and related data to a JSON file for:

- Regular backups
- Migration to another browser or device
- Sharing configuration within a team (sanitize API keys first)

## Import

When a JSON file is selected for import:

- Data is **merged** with existing local data
- On domain conflicts, the imported version of site rules is **kept**

## Partial Import

Supports importing translations, configuration, or glossaries only (exact options depend on the options page UI).
