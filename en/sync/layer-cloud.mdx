Layer Cloud Sync gives Pro and Max users cross-device synchronization for translation data, AI configuration, and glossaries.

## Requirements

**Pro / Max** plan and a signed-in Layer account.

## Synced Content

| Type | Upload / Download |
| --- | --- |
| Translation site data | ✓ |
| AI configuration and custom models | ✓ |
| Personal glossaries | ✓ |

## Access

Import/Export page → **Layer Cloud Sync** buttons.

## Automatic Sync

Users can enable **Automatic Sync** and set an interval (minutes). The background process periodically pushes local changes to the cloud or pulls remote updates.

<Tip>
  On a new device for the first time: sign in → **Pull** from the cloud → then start editing.
</Tip>
