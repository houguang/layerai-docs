Options page sidebar, bottom → **Developer Settings** (bug icon next to the gear).

## Debug Logging

When enabled, the browser console outputs `[LocalLayer]`-prefixed logs to help diagnose collection, replacement, and shared translation issues.

Relevant logs can be attached when submitting feedback (ensure sensitive data is redacted).

## Advanced Options

- [Protected HTML Tags](/en/advanced/protected-tags)
- [Sensitive Data Masking](/en/advanced/sensitive-mask)

## Intended Audience

Aimed at technical users familiar with the DOM and regular expressions; default values need not be changed for typical use.
