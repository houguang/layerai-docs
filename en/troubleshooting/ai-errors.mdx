## Error Reference

| Symptom / Message | Likely Cause | Resolution |
| --- | --- | --- |
| Complete AI configuration first | No default model selected or empty API key | [Model configuration](/en/models/overview) |
| Invalid API key | Incorrect or expired key | Update the key |
| Request timeout | Slow network or slow model response | Reduce [concurrency / chunk size](/en/models/runtime-config) |
| Too many requests (429) | Rate limit hit | Lower concurrency; retry later |
| JSON parse failure | Model did not follow the expected format | Review [prompts](/en/models/prompts) |
| Structure mismatch | Returned keys do not match input | Retry or switch models |
| Insufficient tokens | Platform quota exhausted | [Quotas](/en/account/quotas) or switch to a custom model |

## Custom Model Specifics

- **Endpoint unreachable** — verify URL, VPN, and firewall settings
- **Ollama CORS** — ensure Ollama allows browser origins
- **Mixed content** — HTTPS pages cannot call HTTP local APIs (blocked by the browser)

## Network

Confirm the API endpoint is reachable; corporate proxies may require system proxy configuration or an accessible relay endpoint.
