Layer 云同步为 Pro / Max 用户提供翻译数据、AI 配置与词库的跨设备同步能力。

## 权限要求

**Pro / Max** 套餐 + 已登录 Layer 账号。

## 同步内容

| 类型 | 上传 / 下载 |
| --- | --- |
| 翻译站点数据 | ✓ |
| AI 配置与自定义模型 | ✓ |
| 个人词库 | ✓ |

## 操作入口

导入/导出页 → **Layer 云同步** 各按钮。

## 自动同步

可开启 **自动同步** 并设置间隔（分钟）。后台定时将本地变更推送到云端或拉取远程更新。

<Tip>
  首次在新设备使用时：先登录 → 从云端 **拉取** → 再开始编辑。
</Tip>

## 故障

参见 [同步错误排查](/troubleshooting/sync-errors)。
