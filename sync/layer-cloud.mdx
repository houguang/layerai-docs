Layer Cloud sync gives Pro / Max users cross-device sync for translation data, AI configuration, and glossaries.

## Requirements

A **Pro / Max** plan and a signed-in Layer account.

## What syncs

| Type | Upload / download |
| --- | --- |
| Translation site data | ✓ |
| AI configuration and custom models | ✓ |
| Personal glossary | ✓ |

## Entry point

Import / Export page → **Layer Cloud sync** buttons.

## Automatic sync

You can enable **Automatic sync** and set an interval (minutes). In the background, local changes are pushed to the cloud or remote updates are pulled on a schedule.

<Tip>
  On a new device for the first time: sign in → **pull** from the cloud → then start editing.
</Tip>
