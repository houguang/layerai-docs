Local import and export lets you back up or migrate translation data, AI configuration, and glossaries as JSON without relying on cloud services. Entry point: extension management page → **Import / Export**.

## Export

You can export current **translation sites, AI configuration, custom models, prompts, glossaries**, and more as a JSON file for:

- Periodic backups
- Migrating to another browser or device
- Sharing configuration within a team (redact API keys first)

## Import

Select a JSON file to import. Behavior:

- **Merge** with existing data
- On domain conflicts, **keep the imported version** of site rules

## Partial import

You can import only translations, only configuration, or only glossaries (follow the actual entry points on the extension management page).
