选项页 → **导入/导出**。

## 导出

将当前 **翻译站点、AI 配置、自定义模型、提示词、词库** 等导出为 JSON 文件，用于：

- 定期备份
- 迁移到其他浏览器 / 设备
- 团队内分享配置（注意脱敏 API Key）

## 导入

选择 JSON 文件导入，行为：

- 与现有数据 **合并**
- 域名冲突时 **保留导入版本** 的站点规则

## 分项导入

支持仅导入翻译、仅配置或仅词库（以选项页实际入口为准）。
