Basic settings control the extension UI language, translation target language, theme, and default AI model. Configure these first after installation.

## Open basic settings

  <img src="/assets/images/ui-tour/6_cn.png" alt="Basic settings page: UI language, target language, theme, and account settings" />
</Frame>

## Recommended first-time setup

| Setting | Description | Recommendation |
| --- | --- | --- |
| **Account** | Sign in to unlock related features | Register or sign in with a third-party provider |
| **UI language** | Language of the extension UI | Choose a language you are comfortable with |
| **Target language** | Language to translate into | e.g. `zh-CN` (Simplified Chinese) |
| **Theme** | Light / dark / system | Choose based on preference |

<Warning>
  Changing the target language does not automatically translate existing entries, and does not delete translations already saved in other languages.
  It only affects the language used for new translations going forward.
</Warning>
