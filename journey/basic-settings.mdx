基础配置模块用于设定扩展的界面语言、译文目标语言、主题外观及默认 AI 模型，是安装后的首要配置项。

## 打开基础配置

  <img src="/assets/images/ui-tour/6_cn.png" alt="基础配置页面：界面语言、目标语言、主题与账号设置" />

## 推荐首次配置

| 设置项 | 说明 | 建议 |
| --- | --- | --- |
| **账号设置** | 登录后可使用相关功能 | 注册或使用第三方平台登录 |
| **界面语言** | 扩展 UI 显示语言 | 选择熟悉的语言 |
| **目标语言** | 要翻译的目标语言 | 如 `zh-CN`（简体中文） |
| **主题** | 浅色 / 深色 / 跟随系统 | 按个人偏好选择 |

<Warning>
  修改目标语言不会自动翻译已有词条，也不会删除已经翻译的其它语言的词条，
  只会影响后续新的翻译语言。
</Warning>

## 共享翻译发现（可选）

基础配置中可设定访问站点时，发现匹配共享翻译的处理方式：

- **手动下载** — 网页弹窗询问
- **自动下载** — 静默下载并应用
- **仅图标提醒** — 扩展图标角标提示，在弹窗中手动下载

详见 [共享翻译发现策略](/shared/discover-modes)。
