## 前置条件

- 已完成 [扩展安装](/journey/install)
- 已在 [模型配置](/modules/models) 中选择默认模型并完成 API Key 配置（若使用自定义模型）

## 常见问题

<AccordionGroup>
  <Accordion title="AI 翻译按钮灰色或报错">
    检查 [模型配置](/modules/models) 是否完整，参见 [AI 错误排查](/troubleshooting/ai-errors)。
  </Accordion>
  <Accordion title="保存后页面没有变化">
    确认 **自动替换** 已开启，且该词条未被禁用。
  </Accordion>
  <Accordion title="想翻译整站而不只是当前页">
    使用 [一键采集当前网站](/collection/current-site)。
  </Accordion>
</AccordionGroup>
