This page walks through LayerAI’s most common flow: collect text from a page, translate and save it, then auto-replace on return visits.

<video controls playsInline className="w-full aspect-video rounded-xl" src="/assets/videos/journey/first-translation_zh.mp4" />

## Prerequisites

- You have completed [extension installation](/journey/install)
- You have selected a default model in [Model configuration](/modules/models) (and an API key if using a custom model)

## First visit: translate and save

Use any stable docs page (for example [Core Concepts](/introduction/concepts) on this site).

<Steps>
  <Step title="Open the target page">
    Open the page you want to translate. The extension has not changed the page yet.

    <Frame>
      <img src="/assets/images/journey/step-open-page_zh.png" alt="Tailwind CSS docs page before collection" />
    </Frame>
  </Step>
  <Step title="Collect page text">
    Click the extension icon → **Collect current page** (or use manual collection for a few elements). Source text is extracted into the translation list under that site’s domain.
  </Step>
  <Step title="Translate and review">
    Select entries → **AI one-click translate**. Edit wrong terms in the list; use the [glossary](/modules/glossary) when brand or product names need constraints.

    <Frame>
      <img src="/assets/images/journey/step-ai-translate_zh.png" alt="Translation list for tailwindcss.com with AI one-click translate" />
    </Frame>
  </Step>
  <Step title="Save translations">
    Click **Save**. The page is replaced with your translations immediately, and entries are stored locally in the browser.

    <Frame>
      <img src="/assets/images/journey/step-save-replace_zh.png" alt="Tailwind CSS docs page after save with translations applied" />
    </Frame>
  </Step>
</Steps>

## Later visits: reuse automatically

<Steps>
  <Step title="Open the same page again">
    Refresh, reopen the tab, or return days later. Keep **auto-replace** on.
  </Step>
  <Step title="Confirm auto-replace">
    Matching source text is replaced with your last confirmed translations—no re-translation. Edit an entry in translation management if a sentence needs a tweak.

    <video controls playsInline className="w-full aspect-video rounded-xl" src="/assets/videos/journey/step-refresh-verify_zh.mp4" />
  </Step>
</Steps>

<Tip>
  Translate when content is new or changed; everyday reading is reuse. See [Core Concepts](/introduction/concepts) for the data model behind this flow.
</Tip>

## FAQ

<AccordionGroup>
  <Accordion title="AI translate button is grayed out or errors">
    Check that [Model configuration](/modules/models) is complete; see [AI error troubleshooting](/troubleshooting/ai-errors).
  </Accordion>
  <Accordion title="Page does not change after save">
    Confirm **auto-replace** is on and the entry is not disabled. See [Page replace](/modules/replace).
  </Accordion>
  <Accordion title="I want to translate the whole site, not just the current page">
    Use [Collect current site](/collection/current-site), then process jobs in the [translation queue](/modules/queue).
  </Accordion>
</AccordionGroup>
