LayerAI 是一款**本地优先**的浏览器扩展，支持谷歌，火狐，edge等主流浏览器，面向需要长期、稳定阅读外文网页的个人与团队。与每次打开页面都重新调用 AI 的即时翻译不同，它将页面文本**按站点采集并持久保存**——经 AI 批量翻译或手动精修确认后，再次访问同一页面时**自动替换**原文，无需重复等待或消耗 Token。扩展支持手动框选、一键整页与整站规则三种采集方式，可结合词库约束术语、翻译队列处理批量任务；数据默认存于设备本地，核心功能无需注册账号，亦可按需启用云同步与社区共享翻译包。

## 产品解决什么问题

LayerAI 将外文网页的阅读体验拆成两个独立阶段：**先完成翻译，再在访问时直接使用**。常见即时翻译工具把二者混在一起——每次打开页面都要重新调用 AI，既消耗 Token 与等待时间，也无法沉淀你已确认过的译法。

### 一、翻译：把页面内容变成可复用的译文

经常访问同一外文网站时，依赖浏览器或插件的即时翻译往往**每次结果不一致**——同一句话今天一种译法、明天又变一种；AI 译法也未必准确，且多数工具**无法保存或手动修改**你已确认过的译文，改过的内容下次访问便又丢失。

LayerAI 在页面内完成「**采集 → 翻译 → 保存**」：从网页提取原文并按站点组织词条，支持 AI 批量翻译与手动精修；词库可约束品牌名、产品名等术语，翻译队列可在后台处理整站批量任务。确认后的译文持久保存在本地（亦可云同步或共享），成为可备份、可协作的翻译资产。

### 二、使用：再次访问时自动替换，无需重翻

译文保存后，阅读阶段与翻译阶段分离：你再次打开同一页面时，扩展**自动应用**已保存的译文替换原文，无需等待 AI、无需重复消耗 Token。可随时开关自动替换，或在浮层中查看、微调单条词条。

这一分离让「一次翻译、永久生效」成为常态——翻译投入发生在需要时，日常使用则像阅读母语页面一样直接。

## 支持的浏览器与模型

LayerAI 基于 Chromium 扩展规范开发，并支持多种 AI 翻译后端：

| 类型 | 说明 |
| --- | --- |
| **Chrome / Edge** | 通过 [Chrome 网上应用店](https://chromewebstore.google.com/detail/local-layer-interface-loc/ehhgbbhlookhlindmdkafmekmgkoilfl) 安装 |
| **Firefox** | 通过 [Firefox 网上应用店](https://addons.mozilla.org/zh-CN/firefox/addon/layerai/) 安装 |
| **平台模型** | 登录 Layer 账号后可使用官方接入的大模型，如 GPT、Claude、Gemini 等 |
| **自定义模型** | 支持 OpenAI 兼容 API、Anthropic、Gemini、Ollama 等，详见 [模型配置](/zh/models/overview) |

## 隐私与数据

<Note>
  LayerAI 采用本地优先设计。翻译数据默认存储于浏览器本地，基础能力不依赖账号；扩展不会将用户访问的网页内容用于模型训练。

  登录后可选用云同步与共享翻译等协作能力。站点读写权限仅在采集与页面替换时按需申请，用户可在浏览器扩展设置中随时撤销。数据备份可通过 [本地导入导出](/zh/sync/local-import-export) 或 [Google Drive](/zh/sync/google-drive) 配置完成，数据流向由用户自行掌控。
</Note>

## 适用场景

LayerAI 面向需要长期、稳定外文阅读体验的个人用户与团队，典型内容类型包括：

- **文档与教程** — 技术文档、Wiki、API 参考、在线课程等反复查阅的内容：术语与译法一次校对，长期以稳定译文阅读
- **产品页与帮助中心** — 营销落地页、FAQ、使用手册：整站规则采集与批量 AI 翻译，审校后作为可维护的本地化内容
- **业务系统界面** — ERP、CRM、管理后台等外语运维界面：界面文案相对固定、登录频繁，适合一次性翻译、日常自动应用
- **团队译法协作** — 词库统一品牌与产品术语，通过共享翻译包下载或提交已审校站点译文，避免多人各自为政
