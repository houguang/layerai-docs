LayerAI 通过**浏览器弹窗**、**扩展管理页**与**网页内浮层**三种界面承载不同粒度的操作：弹窗负责当前站点的快捷开关与采集入口，扩展管理页负责批量管理与全局配置，网页浮层则承载单页内的翻译编辑。下文按界面类型说明各区域功能，并在对应位置预留截图位。

## 三种界面如何分工

| 界面 | 入口 | 适合做什么 |
| --- | --- | --- |
| **浏览器弹窗** | 点击工具栏 LayerAI 图标 | 查看当前站点状态、开关自动替换、快速采集、切换替换模式 |
| **扩展管理页** | 弹窗底部「管理」，或右键扩展 → **选项** | 按站点管理词条、队列、词库、模型、同步与全局设置 |
| **网页浮层** | 页面边缘按钮 / 翻译列表 | 在当前页框选采集、编辑词条、AI 翻译与保存 |

日常阅读阶段主要依赖**自动替换**；需要改译法或补翻时，优先使用网页浮层，批量任务则进入扩展管理页。

## 浏览器弹窗

点击工具栏中的 LayerAI 图标可打开弹窗。弹窗始终针对**当前标签页所在站点**展示状态与操作。

<Frame caption="浏览器弹窗全貌（点击工具栏 LayerAI 图标）">
  ![浏览器弹窗全貌：顶栏账号区、当前站点与自动替换、采集功能、替换模式及底部管理入口](/images/ui-tour/popup-overview.png)
</Frame>

从上至下，各区域作用如下：

| 区域 | 位置 | 功能 |
| --- | --- | --- |
| **顶栏 / 账号区** | 弹窗顶部 | 显示 LayerAI 标识；已登录时展示头像与套餐（Free / Pro / Max），未登录时显示「登录」 |
| **当前站点行** | 顶栏下方 | 显示当前域名；右侧开关控制**自动替换**（是否在页面上应用已保存译文） |
| **站点统计** | 站点行下方 | 展示该站已保存词条数与当前页已替换条数 |
| **共享翻译卡片** | 采集区上方（可选） | 发现匹配社区包时出现，提供一键下载入口 |
| **采集功能** | 弹窗中部 | **一键采集当前网站** / **一键采集当前页面** / **手动采集内容**（进入框选模式） |
| **替换模式** | 采集区下方 | 切换**精确替换**或**内容匹配**（影响全站该域名下的替换策略） |
| **底部栏** | 弹窗底部 | **管理** 进入扩展管理页；右侧显示版本号 |

<Tip>
  弹窗关闭后，**自动替换**与**替换模式**仍对该站点生效；再次打开弹窗可确认当前状态。
</Tip>

## 扩展管理页

扩展管理页集中承载批量编辑词条、翻译队列、词库与模型配置等全局管理功能。

<Frame caption="扩展管理页概览（侧边栏 + 翻译管理主区）">
  ![扩展管理页概览：左侧导航与右侧翻译管理内容区](/images/ui-tour/options-overview.png)
</Frame>

### 侧边栏模块

左侧导航按使用频率排列；点击切换右侧主内容区。底部齿轮图标进入**开发者配置**（调试日志、受保护标签等）。

| 模块 | 说明 |
| --- | --- |
| **翻译管理** | 按站点浏览、搜索、编辑词条；进入某站点后可发起 AI 翻译或手动维护 |
| **翻译队列** | 查看批量 AI 翻译任务进度，支持失败重试与任务管理 |
| **词库管理** | 维护本地与平台术语，在 AI 翻译时约束品牌名、产品名等译法 |
| **共享翻译** | 浏览、下载社区共享包，或将本站译文提交至共享社区 |
| **模型配置** | 配置默认模型、翻译提示词与 API 运行时参数 |
| **导入/导出** | 本地 JSON 备份、Layer 云同步、Google Drive |
| **基础配置** | 界面语言、主题、账号、共享发现策略等 |
| **开发者配置** | 侧边栏底部 Bug 图标；调试日志、受保护标签、敏感词脱敏等 |

<Tip>
  扩展管理页适合「整站 / 批量」操作；单页内改几条译文时，可直接在网页浮层的翻译列表中完成，无需切换到此页。
</Tip>

## 网页内浮层

访问已启用扩展的网页时，LayerAI 会在页面内注入交互元素。这些浮层与弹窗、扩展管理页配合：**在弹窗或扩展管理页发起采集后，编辑与保存通常在浮层中完成**。

### 手动采集按钮

<Frame caption="页面边缘的手动采集悬浮按钮">
  ![网页内浮层：贴靠页面边缘的手动采集按钮](/images/ui-tour/overlay-collect-button.png)
</Frame>

- 悬浮于页面边缘，点击后进入**框选采集**模式
- 可在页面上拖拽框选需要翻译的段落，选中的文本会加入翻译列表
- 与弹窗中的「手动采集内容」为同一功能的不同入口

### 翻译列表弹窗

<Frame caption="当前页的翻译列表面板">
  ![网页内浮层：翻译列表弹窗，展示已采集词条与 AI 翻译、保存等操作](/images/ui-tour/overlay-translation-panel.png)
</Frame>

- 展示**当前页**已采集的词条列表
- 支持勾选条目、**AI 一键翻译**、手动编辑译文、**保存**
- 保存后页面原文立即替换；再次访问时由**自动替换**自动应用（需在弹窗中保持开启）

### 共享翻译提示

<Frame caption="发现可下载共享包时的提示（弹窗或角标）">
  ![网页内浮层：共享翻译发现提示](/images/ui-tour/overlay-shared-hint.png)
</Frame>

- 当当前站点存在匹配的社区共享包时，按 [基础配置](/zh/settings/basic) 中的策略以**弹窗卡片**或**图标角标**形式提醒
- 可在弹窗顶部的共享翻译卡片，或扩展管理页 **共享翻译** 模块中完成下载
- 若当前环境暂无可用共享包，此截图可暂时跳过，待有匹配包时再补

<Tip>
  **扩展管理页**管全局与批量，**网页浮层**管当前页——大多数「打开页面 → 采集 → 翻译 → 保存」流程在浮层中即可完成。
</Tip>
