LayerAI 基于 Chromium 扩展规范开发，支持 Chrome、Edge、Brave 等浏览器。安装完成后，扩展可在目标网页上执行文本采集与页面替换。

## 系统要求

- Chromium 内核浏览器（Chrome、Edge、Brave 等）
- 目标网站需授予扩展访问权限

## 安装步骤

<Steps>
  <Step title="获取扩展包">
    从 Chrome Web Store 或团队提供的 `.crx` 安装包获取；亦可通过开发者模式加载未打包扩展。
  </Step>
  <Step title="固定到工具栏">
    在浏览器扩展菜单中将 LayerAI **固定**到工具栏，便于随时打开弹窗。
  </Step>
  <Step title="授予站点权限">
    首次在某网站使用时，浏览器可能提示「读取和更改网站数据」——需授予权限后方可在页面上采集与替换。
  </Step>
  <Step title="打开扩展管理页">
    建议安装完成后先进入 [基础设置](/zh/quickstart/basic-settings)，配置目标语言与默认模型。
  </Step>
</Steps>

## 开发者模式加载（本地构建）

若从源码构建扩展，可按以下步骤操作：

```bash
cd extension
pnpm install
pnpm build
```

随后在浏览器中打开 `chrome://extensions` → 开启**开发者模式** → **加载已解压的扩展程序** → 选择 `extension/.output/chrome-mv3`（或实际构建输出目录）。

## 验证安装

安装完成后，可通过以下方式确认扩展正常工作：

1. 打开任意外文网页
2. 点击 LayerAI 图标，弹窗应正常显示
3. 页面边缘应出现「手动采集」悬浮按钮

若弹窗空白或页面无响应，参见 [故障排查](/zh/troubleshooting/index)。
