基础配置模块用于设定扩展的界面语言、译文目标语言、主题外观及默认 AI 模型，是安装后的首要配置项。

## 打开基础配置

扩展弹窗 → **管理** → 侧边栏 **基础配置**，或直接打开扩展管理页。

## 推荐首次配置

| 设置项 | 说明 | 建议 |
| --- | --- | --- |
| **界面语言** | 扩展 UI 显示语言 | 选择用户熟悉的语言 |
| **目标语言** | 译文写入的语言键 | 如 `zh-CN`（简体中文） |
| **主题** | 浅色 / 深色 / 跟随系统 | 按个人偏好选择 |
| **默认模型** | AI 翻译使用的模型 | 需先在 [模型配置](/zh/models/overview) 中完成 API 设置 |

<Warning>
  修改目标语言不会自动翻译已有词条，只会影响后续新建或 AI 翻译写入的语言字段。
</Warning>

## 共享翻译发现（可选）

基础配置中可设定访问站点时，发现匹配共享翻译的处理方式：

- **手动下载** — 网页弹窗询问
- **自动下载** — 静默下载并应用
- **仅图标提醒** — 扩展图标角标提示，在弹窗中手动下载

详见 [共享翻译发现策略](/zh/shared/discover-modes)。
