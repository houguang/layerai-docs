LayerAI 提供 Free、Pro、Max 三档套餐，在本地翻译能力之上，按层级开放平台模型额度、云同步与共享翻译等协作能力。

## 套餐概览

| 能力 | Free | Pro | Max |
| --- | --- | --- | --- |
| 本地采集与翻译 | ✓ | ✓ | ✓ |
| 自定义 AI 模型 | ✓ | ✓ | ✓ |
| 平台模型 Token | 基础 | 更高 | 最高 |
| Layer 云同步 | — | ✓ | ✓ |
| 共享翻译下载 | 有限 | 更高 | 最高 / 无限 |
| 词库云同步 | — | ✓ | ✓ |

具体额度以官网 [定价页](https://local-layer.com/pricing) 为准。

## 升级

1. 访问 [订阅页](https://local-layer.com/subscription)
2. 选择 Pro / Max 月付或年付
3. 完成支付后扩展内套餐标识自动更新（需保持登录）

## 降级

在 Customer Portal 取消订阅，当前周期结束后恢复 Free 权益。本地数据不会被删除。
