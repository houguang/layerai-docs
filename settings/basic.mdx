Basic settings centralize the extension UI language, translation target language, theme, and account information. Entry point: extension management page → **Basic settings**.

## General settings

| Item | Description |
| --- | --- |
| UI language | Extension UI language |
| Target language | Language key written for translations (for example, zh-CN) |
| Theme | Light / Dark / System |

For a quick start, see [Basic settings](/journey/basic-settings).

## Account

Sign-in, plan, tokens, and shared-download usage. See [Sign-in and account](/account/login).

## Feedback

At the bottom of the settings page you can scan a QR code to join the community group or submit feedback (as shown in the product).
