选项页 → **基础配置**。

## 基本设置

| 项 | 说明 |
| --- | --- |
| 界面语言 | 扩展 UI 语言 |
| 目标语言 | 译文写入的语言键（如 zh-CN） |
| 主题 | 浅色 / 深色 / 系统 |

快速上手见 [基础设置](/quickstart/basic-settings)。

## 账号

登录、套餐、Token 与共享下载用量。见 [登录与账号](/account/login)。

## 问题反馈

配置页底部可扫码加入交流群或提交反馈（以实际展示为准）。
